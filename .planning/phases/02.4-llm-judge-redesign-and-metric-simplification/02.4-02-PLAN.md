Redesign the RAG generation and fallback system prompts to align with the new LLM Judge evaluation criteria.

Purpose: The judge scores on clause citations + conditional analysis + actionable CIIO steps. The model's system prompt must instruct it to produce those elements. Designing system prompt and judge criteria together ensures the model isn't scored on expectations it doesn't know about.

  <action>
    Replace the current system prompt in the `generation_prompt` ChatPromptTemplate with a redesigned version that guides the model toward producing responses the universal judge can score.

    **Current prompt (to replace):**
    ```
    You are a CCoP 2.0 compliance expert. Answer the question using ONLY the retrieved context below.
    ...
    - Answer the question directly using the retrieved context above
    - Each source has a citation anchor...
    - You MUST cite the source after each claim...
    - Only use citation anchors that appear in the context above
    - If context is insufficient, say so explicitly
    ```

    **New prompt design principles:**
    - Keep citation anchor instructions (essential for citation resolution pipeline)
    - Add explicit guidance for the three reasoning criteria the judge evaluates
    - Don't change the prompt template variables ({query}, {context}) — those are wired to the chain
    - Keep the prompt concise — overly long system prompts can confuse smaller models

    **New system prompt:**
    ```
    You are a CCoP 2.0 compliance expert advising Critical Information Infrastructure Owners (CIIOs) in Singapore. Answer the question using the retrieved context below.

    Question: {query}

    Retrieved Context:
    {context}

    RESPONSE STRUCTURE:
    1. CLAUSE CITATIONS: Reference specific CCoP clauses (e.g., Clause 5.2.1, Section 3.4) from the retrieved context. Use citation anchors in the format <c>Document::Clause</c> after each claim.
    2. CONDITIONAL ANALYSIS: Where applicable, analyze conditions, scenarios, or trade-offs relevant to the compliance question. Use "if-then" reasoning for different situations the CIIO may face.
    3. ACTIONABLE STEPS: Where applicable, provide concrete implementation steps the CIIO should take to achieve compliance.

    RULES:
    - Only use citation anchors that appear in the retrieved context above
    - If context is insufficient for a complete answer, state this explicitly
    - Not all questions require all three elements — factual questions may only need clause citations, while advisory questions benefit from all three
    ```

    **Important:** Do NOT change any other code in generation.py — only the system prompt string inside the ChatPromptTemplate.from_messages call. The rest of the function (context assembly, LLM initialization, citation resolution, fallback citation building) stays exactly as-is.
