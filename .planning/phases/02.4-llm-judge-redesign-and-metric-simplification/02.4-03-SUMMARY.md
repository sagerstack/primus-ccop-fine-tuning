# Phase 2.4 Plan 03: Scoring Service Toggle and RAGAs Simplification Summary

Universal judge toggle wired through ScoringService with simplified RAGAs scoring formula and factual_precision metric removed.

## One-liner

ScoringService routes B3, B7-B21 through universal judge when judge_mode="universal", RAGAs scores orthogonal dimensions independently without multiplicative precision penalty.

## What Was Built

### 1. Universal Judge Toggle in ScoringService

**Updated score_response signature:**
- Added `judge_mode: str = "rubric"` parameter (rubric or universal)
- Added `retrieved_contexts: Optional[List[str]] = None` parameter for hallucination check
- Backward compatible: default behavior unchanged

**Routing logic:**
- When `judge_mode == "universal"`:
  - B3, B7-B20: Route to `_score_universal_judge` (was `_score_llm_judge` rubric-based)
  - B21: Route to `_score_universal_judge` (was `_score_b3_hallucination` regex)
  - B1, B2, B4-B6: Stay rule-based (unchanged)
- When `judge_mode == "rubric"` (default):
  - Everything routes exactly as before (zero behavior change)

**_score_universal_judge method:**
- Calls `judge_service.universal_evaluate_response(test_case, response, benchmark_id, retrieved_contexts)`
- On judge_error: returns single EvaluationMetric with name="judge_error", value=0.0
- On success: returns single EvaluationMetric with name="universal_judge", value=evaluation.overall_score
- overall_score computed by JudgeEvaluation.from_universal_judge (0.0 if hallucination, else reasoning_depth/3.0)
- retrieved_contexts propagated for hallucination detection

### 2. Simplified RAGAs Composite Score Formula

**Old formula (Phase 2.3):**
```python
base_score = (factual_recall + factual_precision + answer_relevancy) / 3
ragas_score = base_score * factual_precision  # Multiplicative penalty
```

**New formula (Phase 2.4):**
```python
ragas_score = (factual_recall + answer_relevancy + semantic_similarity) / 3
```

**Changes:**
- factual_precision removed from formula (was penalizing valid alternative reasoning)
- semantic_similarity added to formula (was display-only diagnostic in 2.3)
- No multiplicative penalty - dimensions are independent
- Simple average of three orthogonal quality aspects

**Rationale:**
- LLM Judge handles hallucination detection via claim verification
- RAGAs measures independent quality dimensions:
  - factual_recall: Does response cover ground truth facts?
  - answer_relevancy: Is response relevant to the question?
  - semantic_similarity: How semantically close to reference?
- No need for precision penalty when hallucination checked separately

### 3. factual_precision Metric Removal

**QualityGroup changes:**
- Model Response Quality group metrics: 5 → 4 metrics
- Removed "factual_precision" from metrics list
- Removed "factual_precision" from display_names mapping
- Updated class docstring: "7 evaluation metrics" (was 8)

**RAGAs evaluation service changes:**
- Removed `FactualCorrectness(llm=evaluator_llm, mode="precision")` from evaluate() call
- Removed factual_precision score extraction logic
- Removed factual_precision RagasMetricScore creation
- Updated logger: "factual_recall, answer_relevancy, semantic_similarity" (was "...precision, ...recall...")

**Result:**

- Context metrics: 3 (unchanged) - context_faithfulness, context_precision, context_recall
- Total metrics: 6 RAGAs + 1 LLM Judge = 7 (was 8)

### 4. Path Preservation

## Technical Notes

### Judge Mode Toggle Design

The toggle is implemented at the routing layer (ScoringService) not the judge layer (LLMJudgeService):
- LLMJudgeService has two independent methods: `evaluate_response` (rubric) and `universal_evaluate_response` (universal)
- ScoringService.score_response selects which method to call based on judge_mode parameter
- This enables side-by-side evaluation with both modes for comparison

### RAGAs Formula Rationale

**Why remove precision penalty:**
- Phase 2.3 formula: `base * precision` creates quadratic effect
  - precision=0.2 → score=0.11 (89% reduction)
  - precision=0.9 → score=0.75 (25% reduction)
- Problem: Penalizes valid alternative reasoning not in ground truth
- Solution: LLM Judge checks hallucination separately via claim verification

**Why simple average:**
- factual_recall, answer_relevancy, semantic_similarity are independent dimensions
- No dimension should dominate the others
- Simple average gives equal weight to each quality aspect

### Backward Compatibility

**API:**
- score_response has new optional parameters (judge_mode, retrieved_contexts)
- Existing callers without parameters work identically (default rubric mode)

**JSON Schema:**
- Breaking change: schema_version will increment to 5 in Plan 04
- factual_precision removed from response_quality group
- Old v3/v4 files won't have factual_precision field (expected)

**Behavior:**
- Default rubric mode preserves 100% existing behavior
- Universal mode is opt-in only
