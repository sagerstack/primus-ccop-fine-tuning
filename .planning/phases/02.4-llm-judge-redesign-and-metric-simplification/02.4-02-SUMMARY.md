## Decisions Made

**1. Both prompts use identical RESPONSE STRUCTURE guidance**
- Rationale: Ensures consistent response format regardless of whether RAG retrieval succeeded or fell back to model-only generation. Universal judge evaluates the same dimensions for both modes.

**2. Keep citation anchor format instructions**
- Rationale: Citation resolution pipeline (Plan 01-04) depends on `<c>Document::Clause</c>` format. Removing this would break citation extraction and reference formatting.

**3. Acknowledge not all questions need all three elements**
- Rationale: Factual questions ("What does Clause 5.2.1 say?") may only need clause citations, while advisory questions ("How should we implement MFA?") benefit from all three elements. Explicit acknowledgment prevents forced structure when inappropriate.

**4. CIIO context maintained**
- Rationale: Responses are for Critical Information Infrastructure Owners in Singapore — maintaining this context keeps responses appropriately scoped to the target audience.
