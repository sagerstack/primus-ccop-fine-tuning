    **2. Add universal judge scoring method:**

    Create `_score_universal_judge` static method:
    ```python
    @staticmethod
    def _score_universal_judge(
        test_case: TestCase,
        response: ModelResponse,
        retrieved_contexts: Optional[List[str]] = None,
    ) -> List[EvaluationMetric]:
    ```

    This method:
    - Creates LLMJudgeService() instance
    - Calls `judge_service.universal_evaluate_response(test_case, response, benchmark_id, retrieved_contexts)`
    - On judge_error: returns single EvaluationMetric(name="judge_error", value=0.0, weight=1.0, description=f"judge_error: {evaluation.error_message}")
    - On success: returns single EvaluationMetric(name="universal_judge", value=evaluation.overall_score, weight=1.0, description="Universal judge (reasoning_depth + hallucination)")
    - Note: overall_score is already computed by JudgeEvaluation.from_universal_judge (0.0 if hallucination, else reasoning_depth/3.0)

    **3. Update benchmark routing in score_response:**

    When `judge_mode == "universal"`:
    - B1, B2, B4, B5, B6: Still route to their existing rule-based methods (unchanged)
    - B21: Route to `_score_universal_judge` (instead of `_score_b3_hallucination` regex)
    - B3, B7-B20: Route to `_score_universal_judge` (instead of `_score_llm_judge` rubric-based)

    When `judge_mode == "rubric"` (default):
    - Everything routes exactly as it does now (zero behavior change for existing users)

    Implementation approach: After the existing benchmark_scorers dict, add a conditional check:
    ```python
    if judge_mode == "universal":
        universal_benchmarks = {"B3", "B7", "B8", ..., "B20", "B21"}
        benchmark_key = test_case.benchmark_type.short_name  # or equivalent lookup
        if benchmark_key in universal_benchmarks:
            # For matching benchmark, find it first to confirm it exists
            for bk, scorer in benchmark_scorers.items():
                if test_case.benchmark_type == bk and bk in universal_benchmarks:
                    return ScoringService._score_universal_judge(test_case, response, retrieved_contexts)
    ```

    Then fall through to existing routing for rule-based benchmarks.

    **Important:** Pass `retrieved_contexts` through to `_score_universal_judge`. The existing `_score_llm_judge` does NOT receive retrieved_contexts (rubric path doesn't need them).
  </action>
