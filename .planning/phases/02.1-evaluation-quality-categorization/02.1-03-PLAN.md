  <name>Task 1: Restructure per-test-case ragas serialization into grouped format</name>
  <files>
    src/infrastructure/adapters/repositories/json_result_repository.py
  </files>
  <action>
    Update `_serialize` method to output ragas metrics in grouped structure instead of flat array.

    1. Add import at top: `from domain.value_objects.quality_group import QualityGroup`

    2. Replace the existing ragas serialization block in `_serialize` (the section that builds `serialized["ragas"]`):

       Old format (flat):
       ```json
       "ragas": {
         "error": false,
         "is_rag_response": true,
         "metrics": [
           {"name": "answer_correctness", "score": 0.85, "applicable": true},
           {"name": "faithfulness", "score": 0.90, "applicable": true},
           ...
         ]
       }
       ```

       New format (grouped):
       ```json
       "ragas": {
         "error": false,
         "is_rag_response": true,
         "group_definitions": {
           "retrieval_quality": {
             "display_name": "Retrieval Quality",
             "metrics": ["context_recall", "context_precision"]
           },
           "grounding": {
             "display_name": "Model-RAG Grounding",
             "metrics": ["faithfulness"]
           },
           "response_quality": {
             "display_name": "Model Response Quality",
             "metrics": ["answer_correctness", "answer_relevancy"]
           }
         },
         "retrieval_quality": {
           "context_recall": {"score": 0.75, "applicable": true},
           "context_precision": {"score": 0.80, "applicable": true}
         },
         "grounding": {
           "faithfulness": {"score": 0.90, "applicable": true}
         },
         "response_quality": {
           "answer_correctness": {"score": 0.85, "applicable": true},
           "answer_relevancy": {"score": 0.78, "applicable": true}
         }
       }
       ```

       Implementation:
       - Get all quality groups from QualityGroup.get_all_groups()
       - Map group names to JSON keys: "Retrieval Quality" -> "retrieval_quality", "Model-RAG Grounding" -> "grounding", "Model Response Quality" -> "response_quality"
       - Build group_definitions dict from QualityGroup data
       - For each metric in ragas_eval.metrics, place it in the correct group's dict
       - Keep error handling: if ragas_eval.evaluation_error, still output {"error": true, "error_message": ...}

    3. The `_serialize_with_question` method calls `_serialize` so it inherits the changes automatically.

    4. Handle the case where ragas_eval is None (no RAGAs evaluation): omit the "ragas" key entirely (same as current behavior).
