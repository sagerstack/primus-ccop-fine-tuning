1. **Create IExperimentTracker port** at `src/application/ports/output/i_experiment_tracker.py`:
   ```python
   class IExperimentTracker(ABC):
       @abstractmethod
       def start_run(self, run_name: str, params: Dict[str, Any]) -> None:
           """Start a tracked experiment run and log parameters."""

       @abstractmethod
       def log_metric(self, key: str, value: float) -> None:
           """Log a single metric."""

       @abstractmethod
       def log_metrics(self, metrics: Dict[str, float]) -> None:
           """Log multiple metrics at once."""

       @abstractmethod
       def log_artifact(self, file_path: str) -> None:
           """Log a file as an artifact."""

       @abstractmethod
       def end_run(self) -> None:
           """End the current run."""
   ```

   Keep it minimal. No MLflow-specific concepts in the port.

2. **Create MLflowTracker adapter** at `src/infrastructure/adapters/tracking/mlflow_tracker.py`:
   - Create the `tracking/` directory under `src/infrastructure/adapters/` (add `__init__.py` if needed)
   - Implements IExperimentTracker
   - Constructor takes `tracking_uri: str` and `experiment_name: str`
   - On `start_run`:
     - Call `mlflow.set_tracking_uri(tracking_uri)`
     - Call `mlflow.set_experiment(experiment_name)`
     - Call `mlflow.start_run(run_name=run_name)` — store the run context
     - Log all params via `mlflow.log_params(params)`
   - On `log_metric`: call `mlflow.log_metric(key, value)`
   - On `log_metrics`: call `mlflow.log_metrics(metrics)`
   - On `log_artifact`: call `mlflow.log_artifact(file_path)`
   - On `end_run`: call `mlflow.end_run()`
   - Handle the case where start_run is called without end_run (cleanup)
   - Use context manager pattern internally: wrap mlflow.start_run in try/finally to ensure end_run is always called

3. **Create a NullTracker** in the same file (or a separate file) that implements IExperimentTracker but does nothing — used when `--track` flag is not passed. All methods are no-ops. This avoids if/else tracking checks throughout the codebase.

   ```python
   class NullTracker(IExperimentTracker):
       def start_run(self, run_name, params): pass
       def log_metric(self, key, value): pass
       def log_metrics(self, metrics): pass
       def log_artifact(self, file_path): pass
       def end_run(self): pass
   ```
