# Phase 01.1 Plan 03: ScoringService LLM-as-Judge Migration Summary

Migrated all 15 LLM-judged benchmarks (B3, B7-B20) to unified _score_llm_judge method, removed SemanticSimilarityService dependency, and made B7/B10/B14/B16 operational (no longer NotImplementedError).

## What Changed

### Task 1: Rewire ScoringService benchmark routing

**Scoring mapping after migration:**

| Category | Benchmarks | Method | Count |
|----------|-----------|--------|-------|
| Rule-based | B1, B2, B4, B5, B6, B21 | Various rule-based scorers | 6 |
| LLM-as-Judge | B3, B7-B20 | `_score_llm_judge` | 15 |
| **Total** | | | **21** |

**Methods removed:**
- `_score_reasoning_track` (was semantic similarity for B8, B9, B11, B15, B17, B18, B19)
- `_score_tier3_llm_judge` (renamed to `_score_llm_judge`)

**Methods added:**
- `_score_llm_judge` (unified LLM judge, handles all 15 benchmarks via benchmark_id routing in LLMJudgeService)

**Error handling:**
- Judge errors produce `EvaluationMetric(name="judge_error", value=0.0, description="judge_error: ...")`

### Task 2: Delete SemanticSimilarityService

Deleted `src/domain/services/semantic_similarity_service.py`. The `sentence-transformers` package dependency is retained because the RAG embedding pipeline uses it independently.

## Decisions Made

1. **Unified _score_llm_judge for all 15 benchmarks** -- Single method routes all LLM-judged benchmarks. Benchmark-specific behavior lives in rubric templates (evaluation-rubrics.md), not in code branching. Simpler to maintain and extend.

2. **B3 migrated from hallucination detection to LLM judge** -- B3 (Conditional Reasoning) was incorrectly using hallucination indicator detection. It actually measures reasoning quality for conditional compliance scenarios. LLM judge with B3-specific rubric evaluates the appropriate dimensions.

3. **B21 retains _score_b3_hallucination (rule-based)** -- B21 (Over-Specification/Hallucination Detection) is genuinely about detecting hallucination indicators, so the binary rule-based approach is appropriate. B21 remains in the 6 rule-based benchmarks.
