  <action>
    Rewrite the LLMJudgeService class methods to support benchmark-specific rubric prompts, dynamic dimension parsing, and skip-and-flag error handling.

    **1. Rubric loading mechanism:**

    Add a class-level or instance-level rubric cache. At initialization or first use, load `docs/phase-2/evaluation-rubrics.md` and parse it into a dictionary mapping benchmark short name (e.g., "B8") to the complete rubric prompt template string.

    Parsing approach: The rubric prompts in evaluation-rubrics.md are structured with clear benchmark headers and prompt template blocks. Parse using regex or string splitting on benchmark ID patterns (e.g., `## B8:` or `### B8`). Store each benchmark's complete prompt template as a string with placeholders.

    The rubric file path should be configurable (constructor parameter with default). This avoids hardcoding the path and allows tests to provide a different rubric file.

    **2. Rewrite `evaluate_response` method signature:**

    Change from:
    ```python
    def evaluate_response(self, test_case, response, rubric: Dict[str, str]) -> JudgeEvaluation
    ```

    To:
    ```python
    def evaluate_response(self, test_case: TestCase, response: ModelResponse, benchmark_id: str) -> JudgeEvaluation
    ```

    The `rubric` dict parameter is replaced by `benchmark_id` (e.g., "B8"). The method looks up the rubric prompt template from the loaded rubrics, substitutes placeholders, calls Claude, and parses the response.

    **3. Rewrite `_build_judge_prompt` method:**

    Instead of building a generic prompt with hardcoded rubric dict, this method now:
    - Looks up the rubric template for `benchmark_id` from the cache
    - Substitutes placeholders: `{question}` -> test_case.question, `{response}` -> response.content, `{expected_response}` -> test_case.expected_response, `{key_facts}` -> comma-joined test_case.key_facts, `{clause_reference}` -> test_case.clause_reference
    - Returns the complete prompt string

    If the benchmark_id is not found in the rubric cache, return a JudgeEvaluation.error() immediately with message "No rubric found for benchmark {benchmark_id}".

    **4. Rewrite `_parse_judge_response` method:**

    Parse the new JSON format with dynamic dimensions:
    ```json
    {
      "dimensions": [{"dimension": "gap_prioritization", "score": 2, "weight": 1.0}],
      "justification": "...",
      "confidence": 0.9
    }
    ```

    Steps:
    - Extract JSON from response (handle markdown code blocks — keep existing logic)
    - Parse each dimension into DimensionScore(name=d["dimension"], score=d["score"], weight=d["weight"])
    - Validate scores are integers 0-3 (clamp if out of range, log warning)
    - Use JudgeEvaluation.from_dimensions() to create the evaluation

    **5. Rewrite error handling in `evaluate_response`:**

    Replace the current try/except that returns fallback scores (3/3/3, 0.6):
    ```python
    try:
        judge_prompt = self._build_judge_prompt(test_case, response, benchmark_id)
        if isinstance(judge_prompt, JudgeEvaluation):
            return judge_prompt  # Error from missing rubric
        judge_response = self._call_claude_agent(judge_prompt)
        evaluation = self._parse_judge_response(judge_response)
        return evaluation
    except Exception as e:
        return JudgeEvaluation.error(
            error_message=f"Judge evaluation failed for {benchmark_id}: {str(e)}",
            raw_response=""
        )
    ```

    This is the skip-and-flag pattern: on failure, the test case gets `judge_error=True` with no score, rather than a misleading fallback score.

    **6. Keep `_call_claude_agent` unchanged:**

    The subprocess call to `claude chat` works correctly. No changes needed. Keep the existing timeout (30s) and error handling.

    **Important implementation notes:**
    - The rubric file is loaded ONCE and cached. Do not reload per-call.
    - If the rubric file does not exist at the configured path, log a warning and set the cache to empty dict. All evaluate_response calls will then return JudgeEvaluation.error().
    - Use stdlib logging consistent with the rest of the codebase.
    - Keep DimensionScore and JudgeEvaluation dataclasses at the top of the file (from Plan 01).
