Add mode parameter to IModelGateway, create ModelGateway adapter wrapping LangGraph pipeline, and wire it as the primary gateway in the DI container — replacing OllamaGateway for evaluation runs.

1. **Update IModelGateway interface** — add `mode: str = "hybrid"` parameter to `generate_response`:
   ```python
   async def generate_response(
       self,
       prompt: str,
       model_name: str,
       mode: str = "hybrid",  # NEW: "hybrid", "llm-only", "rag-only"
       temperature: float = 0.7,
       max_tokens: int = 1024,
       ...
   ) -> ModelResponse:
   ```
   Keep all existing parameters. The mode parameter controls LangGraph routing path.

2. **Update OllamaGateway** to accept `mode` parameter (ignore it — OllamaGateway doesn't route, just passes through to Ollama). Add `mode: str = "hybrid"` to its generate_response signature for interface compliance but don't use it.

3. **Create ModelGateway** at `src/infrastructure/adapters/models/langgraph_model_gateway.py`:
   - Implements IModelGateway
   - Constructor takes `settings` and `logger` parameters
   - Lazily creates LangGraph pipeline on first call using `create_rag_pipeline(settings)` from `rag.retrieval.graph` — lazy import to avoid circular dependency (same pattern as container.py)
   - `generate_response` invokes `self._pipeline(prompt, mode=mode)` and maps final_state to ModelResponse:
     - content = final_state["generation"]
     - is_rag_augmented = final_state.get("is_rag_augmented", False)
     - retrieval_attempts = final_state.get("retrieval_attempts", 0)
     - citations = final_state.get("citations", [])
     - reranker_scores = final_state.get("reranker_scores", [])
     - grading_scores = final_state.get("grading_scores", [])
     - error = final_state.get("error", "")
     - Store all above in ModelResponse.metadata dict
   - Mode consistency check: if mode="hybrid" and is_rag_augmented=False, log a warning (per Pitfall 5 from research)
   - Do NOT fall back silently — if pipeline raises, propagate the exception
   - `is_model_available`: try a minimal llm-only pipeline invocation, return True if generation is non-empty
   - `list_available_models`: return [settings.model_name]
   - `get_model_info`: return dict with name, gateway_type="langgraph_rag", available modes

Note: The LangGraph pipeline's `query()` function is synchronous (it calls `graph.invoke()`). ModelGateway.generate_response is async (interface requirement) but calls the sync pipeline. Use `await asyncio.to_thread(self._pipeline, prompt, mode)` or call synchronously within the async method since LangGraph itself is sync.
