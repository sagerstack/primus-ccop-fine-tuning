<objective>
Wire RagasEvaluationService into the evaluation pipeline so RAGAs metrics are produced alongside benchmark scores for every test case. RAGAs results are stored separately from benchmark metrics and do not affect pass/fail determination.

Purpose: Plan 04 creates RagasEvaluationService as an isolated domain service. This plan integrates it into the actual evaluation flow so it runs automatically during `EvaluateModelUseCase.execute()`. Without this wiring, the service exists but is never called.

Output: Every evaluation run produces both Layer 1 (benchmark) and Layer 2 (RAGAs) scores per test case. RAGAs appears as a separate section in JSON output.
</objective>

    **2. Modify _evaluate_test_case() to call both services:**

    After scoring with ScoringService (line 166), add RAGAs evaluation:

    ```python
    async def _evaluate_test_case(
        self,
        test_case: TestCase,
        request: EvaluationRequestDTO
    ) -> EvaluationResult:
        """Evaluate a single test case."""
        # ... existing code for generating response and scoring ...

        # Score response (Layer 1: Benchmark scoring)
        metrics = ScoringService.score_response(test_case, model_response)

        # Evaluate with RAGAs (Layer 2: Quality metrics)
        ragas_evaluation = None
        if self._ragas_service is not None:
            try:
                # Build reference from expected_response + key_facts
                reference = test_case.expected_response or ""
                key_facts = getattr(test_case, 'key_facts', None)

                ragas_evaluation = self._ragas_service.evaluate_response(
                    question=test_case.question,
                    response=model_response.content,
                    reference=reference,
                    retrieved_contexts=None,  # Not available through current IModelGateway
                    key_facts=key_facts if isinstance(key_facts, list) else None,
                )

                if ragas_evaluation.evaluation_error:
                    self._logger.warning(
                        f"RAGAs evaluation error for {test_case.test_id}: {ragas_evaluation.error_message}"
                    )
            except Exception as e:
                self._logger.warning(
                    f"RAGAs evaluation failed for {test_case.test_id}: {str(e)}"
                )

        # Create evaluation result
        result = EvaluationResult(
            test_case=test_case,
            model_response=model_response,
            metrics=metrics,
            ragas_evaluation=ragas_evaluation,
        )

        # Finalize (calculate score and pass/fail — uses benchmark metrics only)
        threshold = self._get_threshold(request)
        result.finalize(threshold=threshold)

        return result
    ```

      ```python
      def _serialize(self, result: EvaluationResult) -> dict:
          """Serialize result to dict."""
          serialized = {
              "result_id": str(result.result_id),
              "test_id": result.test_case.test_id,
              "benchmark": result.test_case.benchmark_type.value,
              "model": result.model_response.model_name,
              "response": result.model_response.content,
              "score": result.overall_score,
              "passed": result.passed,
              "metrics": [
                  {"name": m.name, "value": m.value, "weight": m.weight}
                  for m in result.metrics
              ],
              "tokens": result.model_response.tokens_used,
              "latency_ms": result.model_response.latency_ms,
              "evaluated_at": result.evaluated_at.isoformat(),
          }

          # Add RAGAs results as separate section
          if result.ragas_evaluation is not None:
              ragas_eval = result.ragas_evaluation
              if ragas_eval.evaluation_error:
                  serialized["ragas"] = {
                      "error": True,
                      "error_message": ragas_eval.error_message,
                  }
              else:
                  serialized["ragas"] = {
                      "error": False,
                      "is_rag_response": ragas_eval.is_rag_response,
                      "metrics": [
                          {
                              "name": m.name,
                              "score": m.score,
                              "applicable": m.applicable,
                          }
                          for m in ragas_eval.metrics
                      ],
                  }

          return serialized
      ```

    **Design notes:**
    - `retrieved_contexts=None` is intentional: the current `IModelGateway.generate_response()` returns `ModelResponse` without GraphState documents. When ModelGateway is upgraded (deferred phase), we pass `model_response.retrieved_contexts` here, and context metrics (faithfulness, context_precision, context_recall) activate automatically via RagasEvaluationService's `is_rag` detection.
    - RAGAs is called synchronously inside the async method — `evaluate_response()` is a sync method. This is acceptable because the ragas `evaluate()` function is synchronous (it uses the LLM wrapper internally).
    - Error handling: RAGAs failures are logged as warnings, never block evaluation. The try/except wrapping ensures a broken RAGAs integration cannot prevent benchmark scoring from completing.
