# Phase 1.1 Plan 05: RAGAs Pipeline Integration Summary

**Wire RagasEvaluationService into evaluate pipeline with conditional DI injection and dual-layer JSON output**

## What Was Done

### Task 1: RAGAs Settings and Data Model Changes (7f2e5b2)

**Settings (settings.py):**
- Added `ragas_enabled` (bool, default True) and `ragas_evaluator_model` (str, default "claude-sonnet-4")
- Maps to env vars `CCOP_RAGAS_ENABLED` and `CCOP_RAGAS_EVALUATOR_MODEL` via CCOP_ prefix

**Environment (.env.example):**
- Added `CCOP_RAGAS_ENABLED=true` and `CCOP_RAGAS_EVALUATOR_MODEL=claude-sonnet-4`

**Domain Entity (evaluation_result.py):**
- Added optional `ragas_evaluation` parameter to EvaluationResult constructor
- Added `ragas_evaluation` property accessor
- `calculate_overall_score()` and `determine_pass_fail()` remain unchanged (benchmark metrics only)
- Added `from __future__ import annotations` and TYPE_CHECKING import for RagasEvaluation

**DTOs (evaluation_result_dto.py):**
- Added `RagasMetricDTO` class (name, score, applicable)
- Added `ragas_metrics`, `ragas_is_rag_response`, `ragas_error` fields to EvaluationResultDTO

### Task 2: Pipeline Wiring (0771b9e)

**Use Case (evaluate_model.py):**
- Added optional `ragas_service` parameter to EvaluateModelUseCase constructor
- After ScoringService.score_response() (Layer 1), calls ragas_service.evaluate_response() (Layer 2)
- Passes `retrieved_contexts=None` (GraphState not yet exposed through IModelGateway)
- try/except wrapping ensures RAGAs failures never block benchmark scoring
- Updated `_result_to_dto()` to map RagasEvaluation to DTO fields

**DI Container (container.py):**
- Added `_create_ragas_service` staticmethod factory (returns None when disabled)
- Added `ragas_service` Singleton provider (placed before use cases for attribute ordering)
- Injected `ragas_service` into `evaluate_model_use_case` Factory

**JSON Serialization (json_result_repository.py):**
- Updated `_serialize()` to include optional "ragas" section
- On success: `{"error": false, "is_rag_response": bool, "metrics": [...]}`
- On error: `{"error": true, "error_message": "..."}`
- Omitted entirely when ragas_evaluation is None

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] DeclarativeContainer attribute ordering**

- **Found during:** Task 2
- **Issue:** `ragas_service` provider was placed after `evaluate_model_use_case`, causing `NameError` at class definition time (DeclarativeContainer processes attributes top-to-bottom)
- **Fix:** Moved RAGAs service factory and provider before the Use Cases section
- **Files modified:** src/infrastructure/config/container.py
- **Commit:** 0771b9e

**2. [Rule 1 - Bug] Type annotations using `any` instead of `Any`**

- **Found during:** Task 1
- **Issue:** EvaluationResult used lowercase `any` in `Dict[str, any]` type hints, inconsistent with the `from __future__ import annotations` addition
- **Fix:** Replaced all `Dict[str, any]` with `Dict[str, Any]` in evaluation_result.py
- **Files modified:** src/domain/entities/evaluation_result.py
- **Commit:** 7f2e5b2

## Key Integration Points

```
EvaluateModelUseCase._evaluate_test_case()
  |
  +-- ScoringService.score_response()          --> Layer 1: Benchmark metrics
  +-- ragas_service.evaluate_response()        --> Layer 2: RAGAs quality metrics
  |
  +-- EvaluationResult(metrics=..., ragas_evaluation=...)
         |
         +-- calculate_overall_score()  --> Uses only Layer 1
         +-- determine_pass_fail()      --> Uses only Layer 1
```
