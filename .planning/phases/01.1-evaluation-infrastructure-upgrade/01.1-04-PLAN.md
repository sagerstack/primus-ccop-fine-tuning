<objective>
Create a separate RagasEvaluationService in the domain layer that evaluates RAG pipeline quality using RAGAs metrics. This service is independent from ScoringService (which handles benchmark scoring) and provides a complementary quality assessment layer.

Purpose: Benchmark scoring (Layer 1) evaluates domain-specific compliance quality. RAGAs (Layer 2) evaluates generic response and retrieval quality: Is the answer factually correct? Is it relevant? Is it faithful to retrieved context? Are the right contexts being retrieved? Both layers produce separate scores per test case, enabling richer analysis (a response can score high on RAGAs but low on benchmarks, or vice versa).

Output: RagasEvaluationService with RAGAs metric evaluation, ragas + langchain-anthropic dependencies installed.
</objective>

  <action>
    Create `src/domain/services/ragas_evaluation_service.py` — a domain service that evaluates response quality using RAGAs metrics.

    **Data model:**

    ```python
    @dataclass
    class RagasMetricScore:
        """Single RAGAs metric result."""
        name: str          # e.g., "faithfulness", "answer_correctness"
        score: float       # 0.0-1.0
        applicable: bool   # False if metric was skipped (e.g., faithfulness for non-RAG)

    @dataclass
    class RagasEvaluation:
        """Complete RAGAs evaluation for one test case."""
        metrics: List[RagasMetricScore]
        is_rag_response: bool       # Whether context metrics were evaluated
        evaluation_error: bool      # True if evaluation failed
        error_message: str = ""     # Error details
    ```

    **Service class:**

    ```python
    class RagasEvaluationService:
        """
        RAGAs-based evaluation for RAG pipeline quality.

        Separate from ScoringService (benchmark scoring).
        Produces Layer 2 quality metrics per test case.
        """

        def __init__(self, model_name: str = "claude-sonnet-4"):
            self._model_name = model_name
            self._evaluator_llm = None  # Lazy init

        def _get_evaluator_llm(self):
            """Lazy initialization of RAGAs evaluator LLM."""
            if self._evaluator_llm is None:
                from ragas.llms import LangchainLLMWrapper
                from langchain_anthropic import ChatAnthropic

                llm = ChatAnthropic(model=self._model_name)
                self._evaluator_llm = LangchainLLMWrapper(llm)
            return self._evaluator_llm

        def evaluate_response(
            self,
            question: str,
            response: str,
            reference: str,
            retrieved_contexts: Optional[List[str]] = None,
            key_facts: Optional[List[str]] = None,
        ) -> RagasEvaluation:
            """
            Evaluate a response using RAGAs metrics.

            For all responses: answer_correctness, answer_relevancy
            For RAG responses (retrieved_contexts provided): + faithfulness, context_precision, context_recall, context_relevancy

            Args:
                question: Original question
                response: Model's response
                reference: Ground truth expected response
                retrieved_contexts: List of retrieved document texts (from GraphState.documents)
                key_facts: Key facts for reference enrichment (appended to reference)
            """
    ```

    **Implementation of evaluate_response:**

    1. Build reference text: Combine `reference` with `key_facts` if provided (join key_facts with newlines, append to reference).

    2. Determine if this is a RAG response: `is_rag = retrieved_contexts is not None and len(retrieved_contexts) > 0`

    3. Create SingleTurnSample:
       ```python
       from ragas import SingleTurnSample
       sample = SingleTurnSample(
           user_input=question,
           response=response,
           reference=reference_text,
           retrieved_contexts=retrieved_contexts if is_rag else None,
       )
       ```

    4. Select metrics based on response type:
       ```python
       from ragas.metrics import (
           AnswerCorrectness, AnswerRelevancy,
           Faithfulness, ContextPrecision, ContextRecall,
       )

       evaluator_llm = self._get_evaluator_llm()

       # Base metrics (all responses)
       metrics = [
           AnswerCorrectness(llm=evaluator_llm),
           AnswerRelevancy(llm=evaluator_llm),
       ]

       # Context metrics (RAG responses only)
       if is_rag:
           metrics.extend([
               Faithfulness(llm=evaluator_llm),
               ContextPrecision(llm=evaluator_llm),
               ContextRecall(llm=evaluator_llm),
           ])
       ```

       Note: Use class-based metric instantiation (AnswerCorrectness, not answer_correctness) to pass the evaluator_llm. The CONTEXT.md mentions context_relevancy but check if RAGAs still has it — if not available, skip it and note in implementation.

    5. Create EvaluationDataset and evaluate:
       ```python
       from ragas import EvaluationDataset, evaluate

       dataset = EvaluationDataset(samples=[sample])

       try:
           result = evaluate(dataset=dataset, metrics=metrics)
           scores_df = result.scores[0]  # First (only) sample
       except Exception as e:
           return RagasEvaluation(
               metrics=[],
               is_rag_response=is_rag,
               evaluation_error=True,
               error_message=f"RAGAs evaluation failed: {str(e)}"
           )
       ```

    6. Build RagasEvaluation from scores:
       ```python
       metric_scores = []

       # Map RAGAs metric names to our names
       ragas_metric_names = {
           "answer_correctness": "answer_correctness",
           "answer_relevancy": "answer_relevancy",
           "faithfulness": "faithfulness",
           "context_precision": "context_precision",
           "context_recall": "context_recall",
       }

       for ragas_name, our_name in ragas_metric_names.items():
           if ragas_name in scores_df:
               score = scores_df[ragas_name]
               metric_scores.append(RagasMetricScore(
                   name=our_name,
                   score=float(score) if score is not None else 0.0,
                   applicable=True,
               ))
           else:
               metric_scores.append(RagasMetricScore(
                   name=our_name,
                   score=0.0,
                   applicable=False,
               ))

       return RagasEvaluation(
           metrics=metric_scores,
           is_rag_response=is_rag,
           evaluation_error=False,
       )
       ```

    **Error handling:**
    - If RAGAs evaluation fails (API error, timeout, etc.), return RagasEvaluation with evaluation_error=True
    - If individual metrics return None/NaN, record as 0.0 with applicable=True (the metric was attempted)
    - Use stdlib logging for warnings/errors

    **Important design decisions:**
    - This service does NOT touch ScoringService or benchmark scoring — completely independent
    - The model_name for the evaluator LLM should come from configuration (env var), not hardcoded. Use the constructor parameter with a default that can be overridden.
    - Lazy LLM initialization: Don't load ChatAnthropic until first evaluate_response call
    - Single sample evaluation (not batch): RAGAs evaluate() is called per test case. Batch optimization can be added later if needed.

    **Note on ContextRelevancy:** RAGAs has renamed/reorganized metrics across versions. The service should gracefully handle missing metrics. If ContextRelevancy is not available as a separate metric in the installed version, skip it and document the omission. Do not error out.
