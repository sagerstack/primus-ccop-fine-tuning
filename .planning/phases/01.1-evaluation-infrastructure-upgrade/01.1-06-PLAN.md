  <name>Task 1: Run baseline LLM-only evaluation with tracking</name>
  <files></files>
  <action>
Execute the baseline evaluation run using the fully integrated pipeline.

**Pre-flight checks:**
1. Verify Ollama is running and primus-reasoning model is available: `ollama list`
2. Verify MLflow config is set in .env.local (MLFLOW_TRACKING_URI, MLFLOW_EXPERIMENT_NAME)
3. Verify test case files exist for all 21 benchmarks

**Run baseline evaluation:**
```bash
cd src && python -m presentation.cli.main evaluate run \
    --model primus-reasoning \
    --mode llm-only \
    --track \
    --phase baseline \
    --save
```

**Expected behavior:**
- All 21 benchmarks execute without NotImplementedError
- 15 benchmarks use LLM-as-Judge (Claude subprocess calls)
- 6 benchmarks use rule-based scoring (no Claude calls)
- MLflow run created with params: model=primus-reasoning, mode=llm-only
- MLflow metrics include overall_accuracy and per-benchmark scores
- Results saved to disk AND logged as MLflow artifact

**Troubleshooting:**
- If Claude subprocess fails: Check `claude --version` is installed and authenticated
- If MLflow connection fails: Verify MLFLOW_TRACKING_URI points to reachable Databricks workspace
- If specific benchmarks fail: Note which ones and check evaluation-rubrics.md has that benchmark

If the evaluation encounters errors on specific benchmarks, document which benchmarks failed and why. The important thing is that the pipeline runs end-to-end without crashing.

Record the overall accuracy score for comparison with the existing 49.2% baseline.
