## Decisions Made
- Rubric file path is configurable via constructor parameter (default: docs/phase-2/evaluation-rubrics.md relative to project root). Enables tests to provide alternate rubric files
- Path resolution uses `Path(__file__).resolve().parent.parent.parent.parent` to find project root from service file location
- Rubric parsing approach: regex split on `## B{N}:` headers, then extract code block content after `### Judge Prompt Template` section
- B19 `{related_scenarios}` placeholder handled via `test_case.metadata.get("related_scenarios")` with "N/A" default and list-to-string conversion
- Out-of-range scores (below 0 or above 3) are clamped with a warning log, not rejected
