<objective>
Plumb full I/O capture (system prompt, user prompt with RAG context interpolated, prompt/completion/total token counts, end-to-end latency, full retrieved-context payloads with metadata) from the LLM call boundary (Ollama/ChatOllama) back up through the LangGraph RAG pipeline, through the RagResponse DTO, through the application use case, and into the domain `EvaluationResult` and outbound `EvaluationResultDTO`. Also introduce the `RunId` value object.

Purpose: Addresses bugs #4 (tokens/latency always 0 through the graph path) and #5 (full composed prompt never captured). This is the type-layer foundation — Plan 02 wires `RunId` into entry points and persistence; Plan 03 surfaces the captured data in CLI/reports.
Output: RunId value object, extended GraphState, extended RagResponse, extended ModelResponse, extended EvaluationResult, extended EvaluationResultDTO, wired generation/fallback/rag_response nodes, wired LangGraphRagAdapter, wired OllamaGateway, wired evaluate_model use case.
</objective>
