# Phase 3.1 Plan 02: JSONResultRepository Rewrite + Query Persistence Summary

**One-liner:** Per-run monthly file layout (`{yyyy-MM}/{run_id}-{model}.json`) with sidecar contexts, schema v6 marker, query persistence via `save_query_run`, and `save_batch` demoted to no-op.

## What Was Built

### Task 1: RunId scope encoding + evaluate CLI wiring (commit 5601ff3 — pre-existing from prior session)

`RunId.build_scope(tier, benchmarks, test_ids, total_benchmarks_available)` added as classmethod with full numeric sort for benchmark IDs. Precedence: test_ids > tier > benchmarks > suite. `RunId.for_query(mode, timestamp)` convenience factory added.

Evaluate CLI (`presentation/cli/commands/evaluate.py`) generates `RunId` at entry before building `EvaluationRequestDTO`, prints `Run ID: {value}` to console, and passes `run_id=run_id.value` into the DTO.

`evaluate_model` use case writes `run_id` and `schema_version=6` as first two fields in metadata, and assembles `contexts_by_test_id` dict from results before calling `save_evaluation_run`.

`EvaluationRequestDTO` carries `run_id: Optional[str]` field.

### Task 2: JSONResultRepository rewrite (commit fc494a3)

**New file layout:**
- Per-run file: `src/results/evaluations/{yyyy-MM}/{run_id}-{model}.json`
- Sidecar contexts: `src/results/evaluations/{yyyy-MM}/{run_id}-contexts.json` (only when contexts provided)
- Monthly dir: lazy-created via `_monthly_dir()` on each write

**New/changed methods:**
- `_generate_filename_v6(metadata)` — requires `metadata["run_id"]`; raises `ValueError` if missing
- `_generate_filename_legacy(metadata)` — preserved alias for old `_generate_filename` (no-op callers)
- `_monthly_dir(timestamp_iso)` — parses ISO timestamp, falls back to `utcnow()` on bad input
- `save_evaluation_run(results, metadata, contexts_by_test_id=None)` — writes main JSON + optional sidecar
- `save_query_run(metadata, test_results, contexts_by_test_id=None)` — same layout for query runs
- `save_batch(results)` — logged no-op, body: single `logger.debug` call

**Per-case serialization** — `_serialize()` now includes:
- `system_prompt`, `user_prompt` (from EvaluationResult)
- `prompt_tokens`, `completion_tokens`, `total_tokens` (from ModelResponse)
- `latency_ms` was already present

**IResultRepository** — `save_evaluation_run` signature updated with `contexts_by_test_id` keyword arg; `save_query_run` added as abstract method.

### Task 3: Query persistence (commit fc494a3)

`_execute_query` in `rag/presentation/cli/query.py`:
1. Captures `ts = datetime.utcnow()` before use case call
2. After response displayed, generates `RunId(mode=mode, scope="query", timestamp=ts)`
3. Prints `Run ID: {value}` as dim text
4. Builds `test_results` list with full I/O fields from `RagResponse` (system_prompt, user_prompt, prompt/completion/total tokens, latency_ms, citations, is_rag_augmented, etc.)
5. Builds `contexts_by_test_id` from `response.retrieved_contexts_detailed` (non-empty in hybrid/rag-only)
6. Reads `settings = container.config()` for `model_name`
7. Calls `repo.save_query_run(metadata, test_results, contexts_by_test_id or None)`
8. All wrapped in `try/except`; failure logs warning at `WARNING` level, never raises

`query_compliance.py` — docstring note added that run_id generation and persistence are CLI-layer responsibilities.

## JSON Schema v6 Shape

**Metadata (both eval and query runs):**
```json
{
  "run_id": "eval-run-hybrid-benchmarks-B1-B3-B7-20260421-1430",
  "schema_version": 6,
  "model_name": "primus-reasoning",
  "evaluation_mode": "hybrid",
  "evaluated_at": "2026-04-21T14:30:00",
  ...
}
```

**Per-case test_results[] entry (new v6 fields):**
```json
{
  "test_id": "B3-001",
  "question": "...",
  "response": "...",
  "system_prompt": "You are a cybersecurity compliance expert...",
  "user_prompt": "Context:\n...\n\nQuestion: ...",
  "prompt_tokens": 1240,
  "completion_tokens": 312,
  "total_tokens": 1552,
  "latency_ms": 4821,
  ...
}
```

**Contexts sidecar shape:**
```json
{
  "B3-001": [
    {"text": "5.2.1 Access control...", "citation_id": "c1", "section": "5.2", "clause": "5.2.1", "document": "CCoP", "score": 0.87}
  ]
}
```
