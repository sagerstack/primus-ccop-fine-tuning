# Phase 3.1 Plan 01: Domain Plumbing — I/O Capture Type Layer Summary

**One-liner:** Plumbed full I/O traceability (system/user prompts, prompt/completion/total tokens, latency, retrieved context metadata) from Ollama call boundary through LangGraph state, RagResponse, ModelResponse, EvaluationResult, and EvaluationResultDTO; added RunId frozen VO.

## What Was Built

### Task 1: Type shapes

**`src/domain/value_objects/run_id.py`** (new)
- Frozen dataclass `RunId(mode, scope, timestamp)`
- Validates `mode ∈ {"hybrid", "llm-only", "rag-only"}`
- `value` property renders `eval-run-{mode}-{scope}-{yyyyMMdd}-{HHmm}`
- `for_query(mode, timestamp)` classmethod for ad-hoc query runs

**`src/rag/retrieval/state/graph_state.py`**
- Added 7 fields to `GraphState` TypedDict: `system_prompt`, `user_prompt`, `prompt_tokens`, `completion_tokens`, `total_tokens`, `latency_ms`, `retrieved_contexts_detailed`

**`src/rag/application/ports/i_rag_pipeline.py`**
- Added 7 Pydantic fields to `RagResponse` with sane defaults (all zero/empty)
- `retrieved_contexts_detailed: list[dict]` carries one entry per filtered doc with full metadata
- Existing `retrieved_contexts: list[str]` (RAGAs-facing) retained alongside new field

**`src/domain/entities/model_response.py`**
- Added `prompt_tokens`, `completion_tokens`, `total_tokens` params with `>= 0` validation
- `total_tokens` auto-sums from `prompt_tokens + completion_tokens` when not explicitly provided
- `tokens_used` back-populated from `total_tokens` when `total_tokens > 0` and `tokens_used == 0`
- Added matching property accessors

**`src/domain/entities/evaluation_result.py`**
- Added `system_prompt`, `user_prompt`, `retrieved_contexts_detailed` constructor params (all `Optional`, default `None`)
- `get_performance_summary()` extended to include `prompt_tokens`, `completion_tokens`, `total_tokens`

**`src/application/dtos/evaluation_result_dto.py`**
- Added `system_prompt`, `user_prompt`, `prompt_tokens`, `completion_tokens`, `total_tokens`, `retrieved_contexts_detailed` fields
- All with defaults — zero breaking changes to existing DTO consumers

### Task 2: Graph wiring

**`src/rag/retrieval/nodes/generation.py`**
- Wraps `chain.invoke()` with `perf_counter()` → `state["latency_ms"]`
- Extracts `system_prompt` / `user_prompt` from `formatted_messages` (`.type == "system"/"human"`)
- Reads `response.response_metadata["prompt_eval_count"]` / `["eval_count"]` with `usage_metadata` fallback
- Builds `retrieved_contexts_detailed` list from `filtered_docs` with full metadata copy
- Exception branch: sets latency from elapsed time, zero tokens (no data loss)

**`src/rag/retrieval/nodes/fallback.py`**
- Same prompt/token/latency treatment as generation node
- `retrieved_contexts_detailed = []` (no retrieval on fallback path)

**`src/rag/retrieval/nodes/rag_response.py`**
- Populates `retrieved_contexts_detailed` from `filtered_docs`
- Sets `system_prompt = ""`, `user_prompt = ""`, token counts = 0, `latency_ms = 0` (no LLM call)

**`src/rag/retrieval/graph.py`**
- Added all 7 new fields with zero/empty defaults to `initial_state`

**`src/rag/infrastructure/adapters/langgraph_rag_adapter.py`**
- Forwards all 7 new fields from `final_state.get(...)` into `RagResponse` constructor

### Task 3: Ollama gateway + use case

**`src/infrastructure/adapters/models/ollama_gateway.py`**
- Reads `prompt_eval_count` and `eval_count` from `response_data`
- Passes `prompt_tokens`, `completion_tokens`, `total_tokens` to `ModelResponse`

**`src/application/use_cases/evaluate_model.py`**
- RAG path: builds `ModelResponse` with `rag_response.prompt_tokens/completion_tokens/total_tokens/latency_ms`; captures `system_prompt_captured`, `user_prompt_captured`, `retrieved_contexts_detailed_captured` from `RagResponse`
- Direct gateway path: captures hardcoded system prompt string and `test_case.question` as user_prompt; `retrieved_contexts_detailed_captured = None`
- Passes all three to `EvaluationResult(...)` constructor
- `_result_to_dto`: populates `prompt_tokens`, `completion_tokens`, `total_tokens`, `system_prompt`, `user_prompt`, `retrieved_contexts_detailed` on `EvaluationResultDTO`
