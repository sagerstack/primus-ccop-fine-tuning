## Decisions Made

**Decision 1: Remove Combined Score entirely**
- **Rationale:** Benchmark score (0-1 normalized benchmark grading) and RAGAs score (0-1 composite metric with penalty) measure different things at different scales. Averaging them creates a meaningless hybrid metric.
- **Impact:** Cleaner separation of concerns. Users see two independent quality signals instead of one confusing blended metric.

**Decision 2: Bump JSON schema to v4**
- **Rationale:** response_quality metric list changed (3 metrics → 4 metrics, different names). Consumers need schema version to handle backward compatibility.
- **Impact:** Added backward compat note in docstring: "schema_version 3 files use answer_correctness and hallucination instead of factual_precision/factual_recall/semantic_similarity"

**Decision 3: Persistence delegates to domain entity for ragas_score**
- **Rationale:** Domain entity already centralizes formula logic in `ragas_composite_score` property. Duplicating formula in persistence layer violates single source of truth.
- **Impact:** Persistence layer is now a thin reader: `ragas_score = result.ragas_composite_score`. Formula changes only need domain entity updates.
