<objective>
Replace answer_correctness and hallucination metrics with FactualCorrectness (precision + recall), add SemanticSimilarity as diagnostic, and implement multiplicative penalty scoring formula in the domain and application layers.

Purpose: The current answer_correctness metric blends 75% factual F1 + 25% semantic similarity, masking hallucination behind high semantic overlap. Splitting into separate precision/recall metrics and applying a multiplicative penalty ensures hallucinating responses score dramatically lower.

Output: Updated domain service (new RAGAs metrics), quality groups (new metric names), use case (penalty formula), DTOs (updated descriptions).
</objective>

     ```python
     def _extract_ragas_score(self, result: EvaluationResult) -> Optional[float]:
         """
         Extract composite RAGAs score using multiplicative penalty formula.

         Formula: ragas_score = base_score * factual_precision
         where base_score = (w1*factual_recall + w2*factual_precision + w3*answer_relevancy)
         with equal weights w1=w2=w3=1/3.

         The factual_precision multiplier penalizes hallucinating responses dramatically:
         - Grounded response (precision=0.9): 0.83 * 0.9 = 0.75
         - Hallucinating response (precision=0.2): 0.60 * 0.2 = 0.12
         """
         if result.ragas_evaluation is None:
             return None
         if result.ragas_evaluation.evaluation_error:
             return None

         # Extract required metrics
         metrics = {m.name: m.score for m in result.ragas_evaluation.metrics if m.applicable}

         factual_precision = metrics.get("factual_precision")
         factual_recall = metrics.get("factual_recall")
         answer_relevancy = metrics.get("answer_relevancy")

         if factual_precision is None or factual_recall is None or answer_relevancy is None:
             return None

         # Equal weights
         w1 = w2 = w3 = 1.0 / 3.0
         base_score = w1 * factual_recall + w2 * factual_precision + w3 * answer_relevancy

         # Multiplicative penalty
         ragas_score = base_score * factual_precision
         return ragas_score
     ```

     Note: `semantic_similarity` is intentionally excluded from the formula — it is display-only diagnostic.
