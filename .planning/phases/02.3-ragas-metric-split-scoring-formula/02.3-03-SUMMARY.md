## Lessons Learned

1. **Mock domain properties for delegation testing:** When application layer delegates to domain entity properties (ragas_composite_score), tests must mock the property with correct computation to validate delegation behavior.

2. **Explicit metric value computation in tests:** Computing expected values explicitly in test helpers (base_score * precision) makes test intent clear and catches formula errors early.

3. **Negative test cases for removed metrics:** Testing that old metric names (answer_correctness, hallucination) are NOT found validates complete migration without leftover references.

4. **Ratio tests for dramatic separations:** Testing grounded_score > hallucinating_score * 3 validates multiplicative penalty creates strong signal separation, not just absolute thresholds.
