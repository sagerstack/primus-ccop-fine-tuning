## Summary

Renamed faithfulness to context_faithfulness, added hallucination metric via RAGAs faithfulness with ground-truth context, and fixed overall score normalization bug.

## Changes

### src/domain/value_objects/quality_group.py
- Model-RAG Grounding metrics: `["faithfulness"]` → `["context_faithfulness"]`
- Model Response Quality metrics: added `"hallucination"` (first position)
- Display names: removed `"faithfulness"`, added `"context_faithfulness"` and `"hallucination"`
- Total metrics across 3 groups: 6 → 7

### src/domain/services/ragas_evaluation_service.py
- Restructured from single evaluate() call to three separate evaluations:
  1. Base metrics (answer_correctness, answer_relevancy) — all modes
  2. Hallucination (faithfulness against [ground_truth] as context) — all modes, always applicable
  3. Context metrics (faithfulness→context_faithfulness, context_precision, context_recall) — hybrid only
- Added `_extract_scores()` helper for score extraction
- Non-RAG mode: context_faithfulness, context_precision, context_recall added with `applicable=False`

### src/application/use_cases/evaluate_model.py
- Fixed `_calculate_category_weighted_score()`: now divides `weighted_sum` by `total_weight`
- Single-category evaluation (e.g., only B3) returns category average, not category_avg * weight
