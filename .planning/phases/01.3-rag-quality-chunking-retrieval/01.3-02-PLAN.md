<objective>
Refactor the retrieval pipeline: remove the broken RRF threshold, add cross-encoder reranking between retrieval and grading, and convert grading from a filter to a measurement-only logger. This fixes the end-to-end retrieval failure (100% of results filtered by 0.6 threshold applied to RRF scores in range 0.001-0.033) and adds precision-improving reranking.

Purpose: The 0.6 cosine threshold applied to RRF scores causes 100% retrieval failure. Cross-encoder reranking improves precision@3 by 25-35% over bi-encoder-only retrieval (MS MARCO benchmarks). Together these changes make retrieval functional and precise.

Output: New reranking node, refactored grading node, updated graph topology, new settings fields. No changes to retrieval node itself (it already uses IVectorStore correctly).
</objective>

    1. **Create `src/rag/retrieval/nodes/reranking.py`** — new LangGraph node for cross-encoder reranking:

    **Lazy singleton for cross-encoder model** (same pattern as EmbeddingService lazy init):
    ```python
    import threading
    _cross_encoder = None
    _cross_encoder_lock = threading.Lock()

    def _get_cross_encoder(model_name: str):
        global _cross_encoder
        if _cross_encoder is None:
            with _cross_encoder_lock:
                if _cross_encoder is None:
                    from sentence_transformers import CrossEncoder
                    _cross_encoder = CrossEncoder(model_name)
        return _cross_encoder
    ```

    **`rerank_documents(state: GraphState) -> GraphState`**:
    - Get settings via `get_settings()`
    - Extract query from `state["rewritten_query"]` (fallback to `state["query"]`)
    - Extract documents from `state["documents"]`
    - If no documents: set `state["reranker_scores"] = []`, return state unchanged
    - Get cross-encoder via `_get_cross_encoder(settings.cross_encoder_model)`
    - Build pairs: `[(query, doc.page_content) for doc in documents]`
    - Score: `scores = model.predict(pairs)` — returns numpy array of logits (unbounded, NOT 0-1)
    - Attach `reranker_score` to each document's metadata: `doc.metadata["reranker_score"] = float(score)`
    - Sort documents by score descending
    - Keep top-N via `settings.rerank_top_n`
    - Update state: `state["documents"] = top_docs` (reranked top-N), `state["reranker_scores"] = [float(s) for s in scores]` (ALL scores for logging)
    - Log: number of documents before/after reranking, score range (min/max/mean), which citation_ids made it to top-N

    Follow existing node patterns: stdlib logging, get_settings() inside function, same GraphState update style.
