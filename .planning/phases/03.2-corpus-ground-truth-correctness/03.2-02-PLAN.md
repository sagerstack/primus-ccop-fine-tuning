  In `clause_aware_chunker.py`, add a table-detection branch during chunk_by_clauses:
  - Docling emits markdown tables as blocks with pipe (`|`) rows. Detect blocks where ≥3 consecutive lines start with `|`.
  - For each detected table block found inside a clause's content: emit an additional chunk with `metadata.type="table"`, `metadata.parent_clause=<enclosing clause number>`, `citation_id=f"{document_name}::{clause_number}::table::{index}"`, and a unique chunk id using the same suffix.
  - The parent clause chunk keeps its text (tables remain embedded in the parent for context) — table chunks are ADDITIVE, not replacements. This preserves retrieval on "show me the enumeration matrix" style queries while keeping the parent clause intact.

  Do NOT change the chunker public signature. Tables from the preamble or outside clause bodies can be skipped for this phase (documented as deferred).
  </action>

  Pytest: add `test_table_detected_and_emitted_as_separate_chunk` — fixture markdown with a clause body containing a 4-row pipe table. Assert: 2 chunks emitted (clause + table), table chunk has `metadata.type == 'table'`, `metadata.parent_clause == <clause_number>`. Test passes.
