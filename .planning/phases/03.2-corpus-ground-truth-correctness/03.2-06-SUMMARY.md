# Plan 06 Summary: Audit + Apply Ground Truth Corrections

## Objective (recap)

Audit every v2 ground-truth clause reference against the authoritative inventory, flag hallucinations and semantic mismatches, apply corrections where a clear mapping exists, and mark the rest as `status: "deprecated"`. Close bug #8 (hallucinated clause references).

## What was built

Three-phase execution:

### Phase A — Audit (read-only)
- Adapted `audit_ground_truth_citations.py` to read authoritative Excel (col 8 = clause_reference, col 11 = expected_response) instead of derived JSONL.
- Three-pass audit: (1) ID existence against `clause_inventory.json`, (2) in-text citation regex extraction + existence, (3) semantic mismatch via Qdrant BGE cosine similarity (threshold 0.35).
- Produced `ground-truth-audit-report.md` (197 flags) and `ground-truth-audit-diff.json` (machine-readable).
- Built `audit-remap-proposal.md`: evidence-backed per-cluster remap design with CCoP PDF verbatim quotes.

### Phase B — Review gate (user approval)
- `pipeline-preflight.md` served as the readiness checklist: dry-run totals, idempotency proof, propagation checks, user-decision status.
- User-decision dialogue resolved three open questions:
  - **B02 5.6.4 cluster fabricated timelines** → Option 3 (rewrite ER to CCoP "timely manner" language)
  - **B3 conditional-compliance scope** → expand to all 29 rows (28 per-row + 2 via B03_117 cluster)
  - **B24-022 BONUS finding** → include in Phase C immediately
- User approval granted: "proceed".

### Phase C — Apply (destructive, authoritative)
- Patcher executed: **176 Excel cells modified across 13 clusters**, zero unexpected errors, timestamped `.bak` created.
- Regen executed: **196 JSONL rows updated across 13 benchmark files**, timestamped `.bak` per file, zero orphans.
- Idempotency re-verified post-apply: patcher dry-run produces 0 modifications, regen dry-run produces 0 modifications.
- Post-apply audit: 7 Pass-1 flags (all B05-018 deprecated + B21 audit-exempt), 90 Pass-2 HUMAN_REVIEW in-text citations. All non-HUMAN_REVIEW action counts are zero, satisfying Plan 06 verify criterion.

## Deviation log

- **Audit source switched Excel→JSONL was reversed**: original Plan 06 text assumed JSONL as input to audit. During execution, source-of-truth was flipped (Excel is where experts edit; JSONL is derived). Patcher+regen pattern introduced to respect this. No regression to original plan intent — the corrections still land in JSONL as required.
- **Apply-via-patcher substitutes for JSON-diff decoration workflow**: Plan 06 Task 2 anticipated decorating `ground-truth-audit-diff.json` with `accepted:true/false` per entry. Replaced with per-cluster rule codification in `patch_ground_truth_excel.py`. Rationale: rules are reviewable, versionable, re-runnable; JSON-decoration is one-shot and error-prone. User confirmed approach during Phase B.
- **B3 scope expanded from singleton to full 29-row class**: original singleton approach missed 23 rows. Corrected during Phase B discussion; no verify-criterion impact (strengthens coverage).
