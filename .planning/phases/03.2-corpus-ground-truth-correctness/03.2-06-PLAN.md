<objective>
Audit every v2 ground-truth clause reference against the authoritative inventory, flag hallucinations and semantic mismatches, apply corrections where a clear mapping exists, and mark the rest as `status: "deprecated"`. Produce a reviewable markdown report and a machine-readable JSON diff.

Purpose: Closes bug #8 (hallucinated clause references). The audit script embodies CONTEXT.md's locked decisions: flag-for-human-review (no auto-correction of unclear cases), semantic mismatch pass reads clause body from Qdrant (why sub-goal A must ship first), unsalvageable cases marked deprecated not deleted.
Output: Audit script + report + JSON diff + corrected JSONL files.
</objective>

  <name>Task 1: Audit script — ID existence + semantic mismatch passes + report generation</name>
  <files>src/rag/ingestion/scripts/audit_ground_truth_citations.py, .planning/phases/03.2-corpus-ground-truth-correctness/ground-truth-audit-report.md, .planning/phases/03.2-corpus-ground-truth-correctness/ground-truth-audit-diff.json</files>
  <action>
  Create `src/rag/ingestion/scripts/audit_ground_truth_citations.py`. Responsibilities:

  1. **Load inputs**: `clause_inventory.json` (set of valid `(clause_id, source_doc)` tuples) and every `*.jsonl` under `ground-truth/test-suite/`.

  2. **Pass 1 — ID existence check** on `metadata.clause_reference`:
     - For each citation in `clause_reference` (array of strings), check if `(citation, "CCoP 2.0")` exists in the inventory. CCoP 2.0 is the default source; allow explicit source prefix parsing like `"MAS TRM: 4.1.2"` for multi-regulator cases (B23).
     - Flag if not found.

  3. **Pass 2 — In-text citation check** on `ground_truth.expected_response`:
     - Extract clause-number-like tokens with regex `r"\b(\d+(?:\.\d+)+(?:\([a-z]\))?)\b"` or the phrase-based form `r"[Cc]lause\s+(\d+(?:\.\d+)+(?:\([a-z]\))?)"`.
     - For each extracted citation, check existence in inventory.
     - Flag if not found.

  4. **Pass 3 — Semantic mismatch check** (only on clause_references that PASSED Pass 1):
     - Load Qdrant client, scroll the `ccop_clauses_hybrid` collection filtered by `citation_id == f"CCoP 2.0::{clause_id}"` (or `::{clause_id_without_item_letter}` fallback when item-letter chunks aren't split).
     - If no matching point, flag as "clause valid per inventory but not indexed" (this should be rare post sub-goal A; if frequent, it signals a sub-goal A regression).
     - If a matching point exists, compute semantic similarity between the clause body text (from Qdrant payload) and the test case's `expected_response`. Use BGE embeddings via the existing `EmbeddingService` (the same model used for retrieval). Compute cosine similarity.
     - Threshold: flag mismatches where cosine < 0.35 (conservative — errs on false positives, which is what CONTEXT.md accepts for stronger regression prevention). Developer's discretion per CONTEXT.md: this threshold can be tuned during implementation; record the chosen value in the audit report.

  5. **Correction logic**:
     - For every flagged entry, attempt a nearest-neighbor suggestion: use the embedding of `expected_response` to query Qdrant for the top-1 chunk under `document_source='CCoP 2.0'`, extract its `citation_id`, strip the document prefix, and suggest as the corrected clause. CONTEXT.md locks "flag-for-human-review only" — DO NOT apply the suggestion silently. The suggestion appears in the report as a proposed correction; acceptance is a manual step in Task 2.

  6. **Output two artifacts**:
     - `.planning/phases/03.2-corpus-ground-truth-correctness/ground-truth-audit-report.md`: one section per benchmark, one bullet per flagged case. Each bullet includes: test_id, pass that flagged it (1/2/3), original citation, suggested correction, similarity score (for pass 3), recommended action (CORRECT, DEPRECATE, HUMAN_REVIEW).
     - `.planning/phases/03.2-corpus-ground-truth-correctness/ground-truth-audit-diff.json`: array of `{test_id, pass, field_path, old_value, suggested_value, confidence, reason, date}` — machine-readable change proposals. `reviewer` and `accepted` fields left blank for Task 2 to fill.

  CLI: `python -m rag.ingestion.scripts.audit_ground_truth_citations --inventory src/rag/ingestion/fixtures/clause_inventory.json --test-suite-dir ground-truth/test-suite --report-dir .planning/phases/03.2-corpus-ground-truth-correctness/ --semantic-threshold 0.35`.

  The script is read-only with respect to JSONL — it proposes, humans apply.
