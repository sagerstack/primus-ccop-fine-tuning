# Plan 07 Summary: Validator Hard-Fail + CLI

## Objective (recap)

Lock in Plan 06 corrections by turning the ground-truth validator into a hard-fail gate on clause correctness, wire it as `ccop-eval validate-ground-truth`, and make the eval pipeline skip `status='deprecated'` rows. Manual-run only per CONTEXT.md locked decision.

## What was built

### Task 1 — Validator hard-fail

**Pre-work (residual cleanup from Plan 06):**

- Re-ran Pass-2 audit against clean ground truth: 76 errors remained. Root-cause analysis showed 59 were false positives from a non-context-anchored regex treating any dotted number as a CCoP citation (e.g. supplementary-guide section numbers, verbatim quotes from the Risk Assessment Guide).
- Replaced `_DOTTED_CLAUSE_RE` with context-anchored `_CCOP_ATTRIBUTED_RE` (requires `CCoP` prefix + `§` / `Section` / `clause` / `,`) and `_CLAUSE_PHRASE_RE` (requires the word `clause/Clause`). Rewrote `extract_intext_citations()` accordingly.
- After regex fix: 17 real errors remained — all ER-footer attributions of the form `Reference: CCoP 2.0, <wrong>` that slipped past Plan 06 because the patcher operated on col-8 clause_reference, not col-11 expected_response footer text.
- Extended `patch_ground_truth_excel.py` with `_ER_FOOTER_PATCHES` (17 entries: B05-002/013/015/016/019, B06-002/013/018/019, B07-006/007/008/010/015/017/018/027) and `_apply_er_footer_patches()`. Added `ER_FOOTER` choice to `--cluster` and `--all`. Applied: 17 cells rewritten in authoritative Excel, timestamped `.bak` created, idempotency verified.
- Regenerated b05/b06/b07 JSONL from patched Excel. Post-apply audit: **0 Pass-2 errors, 90 HUMAN_REVIEW** — matching the Plan 06 acceptance contract.

**Validator refactor:**

- Split `main()` in `ground-truth/schema/validate.py` into `run_validation(test_suite_dir, file, inventory_path, use_inventory, semantic_check, semantic_threshold, strict) -> int` (programmatic entry returning an exit code) + a thin argparse `main()` that calls through to it.
- Existing JSON Schema + business rules + clause-reference + semantic-mismatch logic preserved unchanged; only the orchestration layer was refactored.
- Deprecated-skip already in place from Plan 06 (line 276): `if test_case.get("status") == "deprecated": continue` — verified covers both test cases and the Pass-1 inventory gate.

### Task 2 — CLI wrapper + pipeline skip

- New file `src/presentation/cli/commands/validate_ground_truth.py`: Typer `validate_app` using the `invoke_without_command=True` callback pattern so `ccop-eval validate-ground-truth [flags]` runs directly (no subcommand required).
- Validator loaded dynamically via `importlib.util.spec_from_file_location` since `ground-truth/schema/validate.py` lives outside the `src/` package tree. No subprocess, no duplicate flag parsing.
- Flags exposed: `--test-suite-dir`, `--file`, `--inventory`, `--no-semantic`, `--semantic-threshold`, `--strict`. Defaults point at the real test-suite and inventory paths relative to repo root (computed via `Path(__file__).resolve().parents[4]`).
- `src/presentation/cli/main.py`: added the import + `app.add_typer(validate_app, name="validate-ground-truth", help="...")` registration.
- `src/infrastructure/adapters/repositories/jsonl_test_case_repository.py`: added the deprecated-skip filter in `load_by_benchmark()` with a counter + info-level log per skipped test_id.
- Confirmed `grep -r "validate-ground-truth" .github/` → 0 hits. Manual-run only preserved.

## Deviation log

- **Pre-work for Pass-2 regex and ER_FOOTER patches**: not in Plan 07 task list, but was required to make the validator green on clean ground truth. 76 residual errors from Plan 06 would have caused the first verify criterion (`poetry run ccop-eval validate-ground-truth` exits 0 on clean GT) to fail. Fix: regex context-awareness (59 false positives resolved) + patcher extension (17 genuine footer hallucinations corrected). Preserves Plan 06 authoritative-source pattern — all corrections landed in Excel first, then regenerated into JSONL. Bug #8 driver eliminated end-to-end.
- **CLI callback pattern over subcommand**: Plan 07 Task 2 said "Typer subcommand". Used `invoke_without_command=True` callback instead so users type `ccop-eval validate-ground-truth [flags]` rather than `ccop-eval validate-ground-truth run [flags]`. Ergonomically cleaner; no functional impact.
- **Validator-module split**: Plan 07 didn't mandate refactoring `validate.py`, but the clean way to expose a testable exit-code return required splitting `main()` into `run_validation()` + `main()`. Existing argv behavior preserved; new programmatic path added.
