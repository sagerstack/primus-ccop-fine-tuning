## Decisions Made

- Table chunks are additive: the parent clause chunk retains its full text so context-based retrieval still works for clauses that contain tables. Table chunks layer on top and unlock filtered retrieval.
- Pipe-line threshold set at >=3 (heading + separator + at least 1 data row). A 2-line pipe block is not a meaningful table.
- `EXPECTED_CCOP_2_SECTIONS` is a module constant, not env config. The CCoP 2.0 TOC is a structural fact of the document, not a deployment parameter.
- Gate filters on `type='clause'` only — table chunks inheriting a clause's section should not count as evidence that the section is indexed.
