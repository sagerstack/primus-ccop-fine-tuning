<task type="auto">
  <name>Task 2: Post-ingest verification — section presence + phrase scan</name>
  <files>.planning/phases/03.2-corpus-ground-truth-correctness/reingestion-verification.md</files>
  <action>
  Extend the verification markdown with evidence for the two SC gates:

  1. **Section presence (SC #7)**: For each section in ["5.1", "5.2", "5.3", "5.4", "5.5", "5.6", "5.7", "5.8", "5.9", "5.10", "5.11", "5.12"], scroll Qdrant with filter `document_source=="CCoP 2.0" AND section==<section>` and record the point count. Expected: all non-zero. Script:
  ```
  cd src && poetry run python -c "
  from qdrant_client import QdrantClient
  from qdrant_client.models import Filter, FieldCondition, MatchValue
  from infrastructure.config.settings import get_settings
  s = get_settings()
  c = QdrantClient(url=s.qdrant_url)
  for section in ['5.1','5.2','5.3','5.4','5.5','5.6','5.7','5.8','5.9','5.10','5.11','5.12']:
      flt = Filter(must=[FieldCondition(key='document_source', match=MatchValue(value='CCoP 2.0')), FieldCondition(key='section', match=MatchValue(value=section))])
      points, _ = c.scroll(collection_name=s.qdrant_collection_name, scroll_filter=flt, limit=100)
      print(f'{section}: {len(points)} points')
  "
  ```
  Record results in verification markdown. If any section returns 0, task fails — diagnose and escalate.

  2. **Phrase scan (SC #8)**: Fetch all points for document_source=="CCoP 2.0" and grep payloads for "individual accountability" and "individual authentication". Record count of matching points. Expected: >=1 each. Script:
  ```
  cd src && poetry run python -c "
  from qdrant_client import QdrantClient
  from qdrant_client.models import Filter, FieldCondition, MatchValue
  from infrastructure.config.settings import get_settings
  s = get_settings()
  c = QdrantClient(url=s.qdrant_url)
  flt = Filter(must=[FieldCondition(key='document_source', match=MatchValue(value='CCoP 2.0'))])
  all_points = []
  nxt = None
  while True:
      pts, nxt = c.scroll(collection_name=s.qdrant_collection_name, scroll_filter=flt, limit=200, offset=nxt)
      all_points.extend(pts); 
      if nxt is None: break
  for phrase in ['individual accountability','individual authentication']:
      hits = [p for p in all_points if phrase.lower() in (p.payload.get('text') or '').lower()]
      print(f'{phrase}: {len(hits)} hits, examples: {[p.payload.get(\"citation_id\") for p in hits[:3]]}')
  "
  ```

  3. Append both results to the verification markdown with PASS/FAIL labels against SC #7 and SC #8.
  </action>
  <verify>
  Verification markdown contains: (a) section count table showing all 12 sections non-zero, (b) phrase hit counts >=1 for both target phrases with example citation_ids.
  </verify>
  <done>
  SC #7 and SC #8 proven with evidence. Verification markdown committable as phase artifact.
