<task type="auto">
  <name>Task 1: Write build_clause_inventory.py extraction script</name>
  <files>src/rag/ingestion/scripts/__init__.py, src/rag/ingestion/scripts/build_clause_inventory.py, src/rag/ingestion/fixtures/__init__.py</files>
  <action>
  Create `src/rag/ingestion/scripts/` and `src/rag/ingestion/fixtures/` packages (empty `__init__.py` in each).

  Create `src/rag/ingestion/scripts/build_clause_inventory.py`:

  1. Reuse `parse_all_ccop_documents_with_docling(ccop_dir)` from `rag.ingestion.parsers.docling_parser` to get markdown for all 8 CCoP PDFs.

  2. For each document markdown, run a regex pass to extract every clause-number-like token at the start of a line:
     - Primary: `^(\d+(?:\.\d+)+)\s+` for `5.3.1`-style numbers
     - Secondary: `^(\d+(?:\.\d+)+)\([a-z]\)\s+` for `5.3.1(c)`-style item-letters (NOTE: CONTEXT.md says item letters "remain embedded" at chunker level, but they ARE valid clause IDs and MUST appear in the inventory — citations like `5.3.1(c)` in ground truth need to validate).
     - Tertiary: chapter-only matches like `^5\s+[A-Z]` (treat as clause_id "5").

  3. Build `entries: list[dict]` of `{"clause_id": <str>, "source_doc": <str>}`. Deduplicate within each document. source_doc is the document name as returned by the parser (e.g., "CCoP 2.0", "CCoP Response to Feedback", "Guide to Cyber Threat Modelling", etc.).

  4. Emit JSON to `src/rag/ingestion/fixtures/clause_inventory.json` with top-level structure:
     ```
     {"generated_at": <iso_ts>, "source_docs": [<list of 8>], "entries": [{"clause_id": "5.3.1", "source_doc": "CCoP 2.0"}, ...]}
     ```
     Sort entries by (source_doc, clause_id) for stable diffs.

  5. CLI: `python -m rag.ingestion.scripts.build_clause_inventory --ccop-dir ../ccop-official` with `--output` flag defaulting to the fixtures path. Log entry count per document.

  Do NOT include clause text or titles — CONTEXT.md locks the schema as minimal (`{clause_id, source_doc}`). Semantic mismatch audit in Plan 06 reads text from Qdrant, not from the inventory.
  </action>
  <verify>
  `cd src && poetry run python -m rag.ingestion.scripts.build_clause_inventory --ccop-dir ../ccop-official` exits 0.
  `src/rag/ingestion/fixtures/clause_inventory.json` exists, contains > 100 entries, and contains `{"clause_id": "5.3.1", "source_doc": "CCoP 2.0"}` and `{"clause_id": "5.3.1(c)", "source_doc": "CCoP 2.0"}`.
  `grep -c '"clause_id"' src/rag/ingestion/fixtures/clause_inventory.json` returns the entry count.
  </verify>
  <done>
  Reproducible extraction script lands the canonical inventory. Script is re-runnable when PDFs update. SC #11 satisfied.
  </done>
