  <name>Task 1: Implement QdrantVectorStoreAdapter</name>
  <files>src/rag/infrastructure/adapters/qdrant/qdrant_vector_store_adapter.py</files>
  <action>
    Create `QdrantVectorStoreAdapter` implementing `IVectorStore`.

    **Constructor:**
    ```
    __init__(self, client: QdrantClient, collection_name: str, embedding_service: EmbeddingService)
    ```
    - Store client, collection_name, embedding_service

    **similarity_search_with_scores method:**
    1. Generate dense embedding via `self.embedding_service.embed_query(query)`
    2. Generate sparse embedding via `self.embedding_service.embed_sparse(query)`
    3. Execute hybrid search using `self.client.query_points()`:
       - `collection_name`: from constructor
       - `prefetch`: Two entries:
         - Dense: `{"query": dense_vector, "using": "dense", "limit": k * 2}`
         - Sparse: `{"query": SparseVector(indices=..., values=...), "using": "sparse", "limit": k * 2}`
       - `query`: `FusionQuery(fusion=Fusion.RRF)` for Reciprocal Rank Fusion
       - `limit`: k
       - `query_filter`: build from filter dict if provided (see _build_filter)
       - `with_payload`: True
       - `with_vectors`: False (don't return raw vectors)
    4. Convert results to `List[tuple[Document, float]]`:
       - For each `ScoredPoint` in results:
         - Create `Document(page_content=point.payload.get("text", ""), metadata={field: value for all payload fields except "text"})`
         - Use `point.score` as the similarity score
       - Return list of (Document, score) tuples

    **_build_filter private method:**
    - Input: `Dict[str, Any]` where keys are metadata field names, values are match values
    - Output: `Filter(must=[FieldCondition(key=k, match=MatchValue(value=v)) for k, v in filter_dict.items()])`
    - Import from `qdrant_client.models`: `Filter`, `FieldCondition`, `MatchValue`, `ScoredPoint`, `SparseVector`, `FusionQuery`, `Fusion`, `Prefetch`

    **_to_document private method:**
    - Input: `ScoredPoint`
    - Output: `Document` with page_content from payload["text"] and metadata from remaining payload fields

    Logging: Log query (truncated to 80 chars), result count, score range (min/max) at INFO level.

    Important from research pitfalls:
    - Use SparseVector model for sparse queries (not raw dict)
    - Use Prefetch model for prefetch entries
    - Use FusionQuery for the query parameter
  </action>

  </verify>

<task type="auto">
  <name>Task 2: Implement QdrantIndexerAdapter</name>
  <files>src/rag/infrastructure/adapters/qdrant/qdrant_indexer_adapter.py</files>
  <action>
    Create `QdrantIndexerAdapter` implementing `IIndexer`.

    **Constructor:**
    ```
    __init__(self, client: QdrantClient, collection_name: str, embedding_service: EmbeddingService)
    ```

    **index_chunks method:**
    1. Delete existing collection if it exists (delete+recreate for local dev, per research recommendation):
       ```
       if self.client.collection_exists(self.collection_name):
           self.client.delete_collection(self.collection_name)
       ```
    2. Create collection with hybrid vector config:
       ```
       vectors_config={"dense": VectorParams(size=1024, distance=Distance.COSINE)}
       sparse_vectors_config={"sparse": SparseVectorParams(modifier=Modifier.IDF)}
       ```
       CRITICAL: `modifier=Modifier.IDF` is required for BM25 semantics (pitfall from research).
    3. Prepare points for upload:
       - Extract texts from chunks: `[chunk.text for chunk in chunks]`
       - Generate dense embeddings in batch: `self.embedding_service.embed_documents(texts)`
       - Generate sparse embeddings in batch: `self.embedding_service.embed_sparse_batch(texts)`
       - Build `PointStruct` for each chunk:
         - `id`: Use integer hash of chunk.id (Qdrant requires int or UUID for point IDs). Use `uuid.uuid5(uuid.NAMESPACE_URL, chunk.id)` to generate deterministic UUID from string ID.
         - `vector`: `{"dense": dense_vec, "sparse": SparseVector(indices=sparse["indices"], values=sparse["values"])}`
         - `payload`: Include ALL metadata fields from `chunk.metadata` model (document_source, section, subsection, clause, citation_id, page, document_type) PLUS `text` field with chunk.text, PLUS `chunk_id` with original chunk.id
    4. Upload in batches of 100 using `self.client.upsert()` with `wait=True`
    5. Log: total chunks indexed, collection name
    6. Return collection_name

    **verify_index method:**
    - Get collection info: `self.client.get_collection(index_name)`
    - Run sample search using `similarity_search_with_scores`-like logic (generate embeddings, query_points)
    - Return dict with:
      - `collection_name`: index_name
      - `point_count`: from collection info
      - `result_count`: number of results from sample query
      - `results`: list of dicts with citation_id, section, score from sample results

    Logging: Log progress during indexing (batch N of M), total time, collection stats.

    Import from `qdrant_client.models`: `VectorParams`, `Distance`, `SparseVectorParams`, `Modifier`, `PointStruct`, `SparseVector`
  </action>
