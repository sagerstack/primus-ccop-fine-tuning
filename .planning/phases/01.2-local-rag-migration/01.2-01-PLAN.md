    **EmbeddingService** (`src/rag/infrastructure/adapters/qdrant/embedding_service.py`):

    Class `EmbeddingService` wrapping sentence-transformers (dense) and FastEmbed (sparse):

    ```
    __init__(self, dense_model_name: str, sparse_model_name: str, device: str = "auto"):
    ```
    - Lazy load dense model (`SentenceTransformer`) on first use (not in __init__)
    - Lazy load sparse model (`SparseTextEmbedding`) on first use
    - Thread-safe lazy initialization using `threading.Lock` with double-checked locking
    - Store model names in __init__, construct models in `_ensure_dense_model()` and `_ensure_sparse_model()`

    Methods:
    - `embed_query(text: str) -> List[float]`: Dense embedding for queries. Prepends BGE query prompt: "Represent this sentence for searching relevant passages: ". Returns list of floats. Normalizes embeddings.
    - `embed_documents(texts: List[str]) -> List[List[float]]`: Batch dense embeddings for documents. No query prompt prefix. Uses `batch_size=32`, `show_progress_bar=True`, `normalize_embeddings=True`.
    - `embed_sparse(text: str) -> Dict[str, Any]`: Single sparse embedding via FastEmbed. Returns `{"indices": [...], "values": [...]}`.
    - `embed_sparse_batch(texts: List[str]) -> List[Dict[str, Any]]`: Batch sparse embeddings.
    - `embedding_dimension` property: returns 1024 (bge-large-en-v1.5 dimension)

    Logging: log model loading (INFO), batch progress (DEBUG).

    Important anti-patterns to AVOID (from research):
    - Do NOT hardcode model names -- accept via constructor params
    - Do NOT skip normalize_embeddings for COSINE distance
    - Do NOT use query prompt for documents (only for queries)
