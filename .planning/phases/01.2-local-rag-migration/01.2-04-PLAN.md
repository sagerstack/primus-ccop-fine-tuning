         - Return `QdrantIndexerAdapter(client=client, collection_name=settings.qdrant_collection_name, embedding_service=embedding_service)`
      2. Elif `settings.databricks_host` is set: import and create `DatabricksIndexerAdapter`
         - Return `DatabricksIndexerAdapter(settings=settings)`
      3. Else: log warning and return None

    ```python

        settings=config,
        logger=logger,
    ```
