<objective>
Wire the Neo4j graph in as a retrieval provider only. Define an `IGraphRetrievalProvider` port, implement a `Neo4jGraphRetrievalAdapter` doing entity-anchored (local) retrieval via a neo4j-graphrag Vector/VectorCypher retriever, add a `graph_retrieve_documents` LangGraph node that returns contexts in hybrid's Document shape, and route `--mode graphrag` so it swaps ONLY the retrieval node — the existing primus `generate` node is untouched (D-06). Provider selection lives in the DI container, mirroring the Qdrant/Databricks adapter pattern, leaving a Phase-10 second-provider seam (D-11).

Purpose: isolate retrieval (graph vs vector) as the single changed variable so the comparison measures retrieval, not the generator. Runs only after the KG is inspected/validated in Plan 03.
Output: port, Neo4j adapter, graph_retrieval node, routing + DI wiring.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user query → Cypher/retriever | Untrusted question text drives graph retrieval |
| retrieval node → Neo4j | Read queries over Bolt with credentials |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-12 | Injection (Tampering) | VectorCypherRetriever retrieval_query | mitigate | Static parameterized Cypher; user query passed only as embedded vector/query_text param — never string-formatted into Cypher (grep-gated) |
| T-09-13 | Information Disclosure | Neo4j creds in adapter | mitigate | Credentials from settings/.env.local; driver auth tuple; not logged |
| T-09-14 | Tampering | Graph provider bypassing generator | mitigate | Provider returns contexts only (D-06); generation node unchanged; asserted by "generation.py not modified" acceptance |
| T-09-15 | Denial of Service | Unbounded neighborhood expansion | mitigate | retrieval_query bounds hops (1-hop) and top_k = rag_retrieval_top_k |
</threat_model>
