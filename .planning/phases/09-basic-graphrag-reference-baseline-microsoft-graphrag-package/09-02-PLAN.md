<objective>
Build the emergent CCoP knowledge graph in Neo4j and expose it as `ccop-eval graph build`. The builder feeds the exact Docling-parsed CCoP markdown the hybrid stack uses into neo4j-graphrag's `SimpleKGPipeline` with NO schema (un-governed extraction), using gpt-4o-mini (OpenRouter) for entity/relationship extraction and bge-large-en-v1.5 (in-process) for chunk embeddings written to a 1024-dim cosine vector index.

Purpose: deliver a buildable, repeatable KG early (D-17) so the graph can be inspected/iterated in Plan 03 before any retrieval/eval is wired. Keeping the extraction behind one builder class preserves the Phase-10 additivity seam (D-16).
Output: `EmergentKGBuilder`, corpus loader, `graph` CLI namespace with `build`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build pipeline → OpenRouter | CCoP text + API key sent to the extraction LLM |
| build pipeline → Neo4j | Writes nodes/relationships/embeddings over Bolt |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-05 | Information Disclosure | OpenRouter API key in EmergentKGBuilder | mitigate | Key read from settings.openrouter_api_key (env/.env.local); never logged or hardcoded in kg_builder.py |
| T-09-06 | Denial of Service | Extraction cost / runaway build | accept | Local, one-off build over a fixed 7-doc corpus; `--drop` guarded, default off; failures counted not retried infinitely |
| T-09-07 | Tampering | `--drop` wipes the graph | mitigate | Default `--no-drop`; destructive path is explicit opt-in for iteration rebuilds (D-19) |
| T-09-08 | Repudiation | Silent extraction failures blur the baseline | mitigate | BuildStats reports failures + extraction_failure surface (feeds Plan 03 metric); no silent swallow beyond idempotent index-exists |
</threat_model>
